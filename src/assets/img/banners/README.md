# Imágenes de Banners - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: 1920x600px o 1920x800px
- **Formato**: JPG o WebP
- **Peso máximo**: 200-300KB por imagen (optimizadas para web)
- **Aspect ratio**: 16:9 o similar

## Banners de Páginas Principales

Guarda estas imágenes con los siguientes nombres:

### Páginas principales
- `banner-inicio.jpg` - Página de Inicio
- `banner-nosotros.jpg` - Página Acerca de Nosotros
- `banner-productos.jpg` - Página de Productos

## Notas
- Todas las imágenes deben tener buena resolución
- Asegúrate de que el texto sea legible si hay overlay
- Considera el espacio para el título de la página sobre el banner
- Optimiza las imágenes antes de subirlas (usa herramientas como TinyPNG o Squoosh)
