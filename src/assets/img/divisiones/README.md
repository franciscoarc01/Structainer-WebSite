# Imágenes de Divisiones - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: 800x600px o 1200x900px (aspect ratio 4:3)
- **Formato**: JPG o WebP
- **Peso máximo**: 150-250KB por imagen
- **Calidad**: Alta resolución, imágenes representativas de cada división

## Nomenclatura de Archivos

### Formato sugerido:
`division-[nombre-division]-[variante].jpg`

## Logos de Clientes por División
Para mostrar clientes destacados de cada división:
- `cliente-[division]-[nombre-cliente].jpg` o `.png`

**Ejemplos**:
- `cliente-automotriz-gkn.png`
- `cliente-retail-oxxo.png`
- `cliente-gastores-bachoco.png`

## Notas
- Usa imágenes reales de proyectos de Structainer en cada división
- Muestra la variedad de soluciones que ofrece cada división
- Incluye imágenes exteriores e interiores
- Todas en minúsculas
- Usa guiones (-) en lugar de espacios
- La imagen `-principal` será la que se muestre en tarjetas/listados
