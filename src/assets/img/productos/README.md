# Imágenes de Productos - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: 800x600px o 1200x900px (aspect ratio 4:3)
- **Formato**: JPG o WebP
- **Peso máximo**: 150-200KB por imagen
- **Calidad**: Alta resolución para zoom/lightbox

## Nomenclatura de Archivos

### Formato sugerido:
`producto-[categoria]-[nombre-descriptivo].jpg`

### Ejemplos por categoría:

#### Módulos Habitacionales

- `producto-habitacional-dormitorio-ejecutivo.jpg`
- `producto-habitacional-casa-completa.jpg`

## Notas
- Usa nombres descriptivos y consistentes
- Todas en minúsculas
- Usa guiones (-) en lugar de espacios o guiones bajos
- Incluye múltiples ángulos del mismo producto con sufijos: `-frontal`, `-lateral`, `-interior`
- Ejemplo: `producto-oficina-modular-frontal.jpg`, `producto-oficina-modular-interior.jpg`
