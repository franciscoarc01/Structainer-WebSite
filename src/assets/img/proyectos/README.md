# Imágenes de Proyectos - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: 1200x800px o 1600x1200px (aspect ratio 4:3 o 3:2)
- **Formato**: JPG o WebP
- **Peso máximo**: 200-300KB por imagen
- **Calidad**: Alta resolución para galería/lightbox

## Nomenclatura de Archivos

### Formato sugerido:
`proyecto-[cliente]-[tipo-proyecto]-[numero].jpg`

### Ejemplos de proyectos actuales:

## Sufijos útiles para múltiples fotos del mismo proyecto:
- `-exterior` - Vista exterior
- `-interior` - Vista interior
- `-fachada` - Fachada frontal
- `-proceso` - Durante construcción
- `-terminado` - Proyecto finalizado
- `-detalle` - Detalles específicos
- `-01`, `-02`, `-03` - Para múltiples imágenes

## Notas
- Usa nombres descriptivos del cliente y tipo de proyecto
- Todas en minúsculas
- Usa guiones (-) en lugar de espacios
- Mantén consistencia en los nombres
- Incluye el número de imagen si hay varias del mismo proyecto
