# Imágenes de Inicio - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: Varía según sección
- **Formato**: JPG o WebP
- **Peso máximo**: 150-300KB por imagen
- **Calidad**: Alta resolución, imágenes impactantes

## Nomenclatura de Archivos

### Formato sugerido:
`inicio-[seccion]-[descripcion].jpg`

## Dimensiones Específicas por Sección

### Hero/Carousel
- **Dimensión**: 1920x800px o 1920x1080px
- **Aspect ratio**: 16:9 o 21:9
- **Peso**: 250-400KB

### Tarjetas de División/Productos
- **Dimensión**: 800x600px o 600x400px
- **Aspect ratio**: 4:3 o 3:2
- **Peso**: 100-150KB

### Proyectos Destacados
- **Dimensión**: 1000x750px o 1200x900px
- **Aspect ratio**: 4:3
- **Peso**: 150-200KB

### Iconos
- **Formato**: SVG (preferido) o PNG transparente
- **Dimensión**: 64x64px, 128x128px, o 256x256px
- **Peso**: Mínimo posible

### Logos de Clientes
- **Formato**: PNG transparente o SVG
- **Dimensión**: Variable, mantener aspect ratio
- **Peso**: 20-50KB cada uno

## Notas Importantes

### Para el Hero/Carrusel:
- Usa imágenes impactantes que muestren proyectos reales
- Asegúrate de que haya espacio para texto overlay
- Considera el contraste para que el texto sea legible
- Todas deben tener la misma dimensión y aspect ratio

### Para las tarjetas:
- Usa imágenes consistentes en tamaño y estilo
- Mantén el mismo aspect ratio en toda la sección
- Optimiza para web (usa WebP si es posible)

### General:
- Todas en minúsculas
- Usa guiones (-) en lugar de espacios
- Mantén consistencia en los nombres
- Usa números con dos dígitos (01, 02, 03) para ordenar
- Prioriza imágenes de calidad profesional
- Usa fotos reales de Structainer, no stock photos

## Estructura de Carpetas Opcional

Si tienes muchas imágenes, puedes crear subcarpetas:
```
inicio/
├── hero/           (Imágenes del hero/carousel)
├── divisiones/     (Preview de divisiones)
├── productos/      (Productos destacados)
├── proyectos/      (Proyectos destacados)
├── testimonios/    (Fotos de testimonios)
├── iconos/         (Iconos SVG)
└── logos/          (Logos de clientes)
```
