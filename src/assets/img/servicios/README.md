# Imágenes de Servicios - Structainer

## Especificaciones Técnicas
- **Dimensiones recomendadas**: 800x600px o 1000x750px (aspect ratio 4:3)
- **Formato**: JPG o WebP
- **Peso máximo**: 150-200KB por imagen
- **Calidad**: Alta resolución, imágenes que representen cada servicio

## Nomenclatura de Archivos

### Formato sugerido:
`servicio-[nombre-servicio]-[variante].jpg`

## Tipos de imágenes recomendadas:

### Para cada servicio considera incluir:
1. **Imagen principal** - Vista general del servicio
2. **Proceso** - Equipo trabajando/servicio en acción
3. **Resultado** - Resultado final del servicio
4. **Detalle** - Aspecto técnico o de calidad

### Ejemplos de variantes:
- `servicio-instalacion-obra-proceso.jpg` - Durante instalación
- `servicio-instalacion-obra-equipo.jpg` - Equipo de trabajo
- `servicio-instalacion-obra-terminado.jpg` - Instalación completada
- `servicio-diseno-arquitectonico-planos.jpg` - Mostrando planos
- `servicio-diseno-arquitectonico-3d.jpg` - Renderizado 3D

## Notas
- Usa imágenes que muestren acción y profesionalismo
- Preferible mostrar personal de Structainer trabajando
- Incluye equipo, herramientas y procesos reales
- Todas en minúsculas
- Usa guiones (-) en lugar de espacios
- Mantén consistencia en los nombres
